Call flow demo: AI call to CRM, per agency

Voice: ... CRM: ... Test data only. Numbers 555-01xx are reserved test numbers. This is your own sandbox, not shared with other visitors.

Webhooks, routing, duplicate blocking and usage counts are live. Voice uses the browser's voice and the CRM writes to a stand-in table instead of GHL. The real GHL API calls are in the code and go live once test sub-account tokens are added.

Chrome is best if you want to use voice. Typed answers work the same on any phone or computer, with no mic needed.

Try it yourself (about 3 minutes)

  1. Call Agency A. Pick "Agency A line" and press "Start voice call". Answer with your name, what you need, and yes. Or press "Quick test (no voice)" to skip the talking.
    What this proves: a call result is sent to the server with the call ID, the number dialed, and the caller's number.
  2. See it land in the CRM. Watch the contacts table and the event log on the right (below, on a phone).
    What this proves: the call creates a contact, adds tags and a note, and queues a text-back.
  3. Resend the same event. Press "Resend same event".
    What this proves: the same call ID is skipped, so no second contact, note, or text is created.
  4. Send 2 copies at once. Press "Send 2 copies at once".
    What this proves: even two copies at the same moment make only one contact. The duplicate still gets a 200, so Vapi or Telnyx stop retrying.
  5. Switch to Agency B. Pick "Agency B line" and press "Quick test (no voice)" with the same caller phone.
    What this proves: the same caller on a different agency is a separate contact, and each agency has its own usage count for billing.
